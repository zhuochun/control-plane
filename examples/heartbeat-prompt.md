# aicp heartbeat

Use the configured aicp tools to complete one truthful inspection/intake Run.
Start one Run and follow its captured AGENTS.md and USER.md. Consume every
required Interest, changes, and user_inputs continuation; Attention is optional.
Inspect only selected Watchers, preserve existing Item identity and user state,
record input handling, and finish with honest coverage and limitations.

For authorized follow-through without a source Run, recover pending/blocked
Item delegations and use current applicable guidance. Read get_settings when
you need current instructions or context-editing guidance; do not replace an
active Run's captured instructions with live settings. Keep progress on Items.

For executor assignments, use [the short handoff example](delegation-handoff.md)
with assigned-Item context rather than copying this global protocol.

Source credentials, source tools, scheduler cadence, and execution budgets
belong in the external agent/scheduler configuration.
